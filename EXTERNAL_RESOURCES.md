# External BJJ Data Resources

This document contains links to external sources of Brazilian Jiu-Jitsu data, APIs, and datasets that can be used for research, analysis, and data collection.

## Competition Data Sources

### Major Organizations

#### ADCC (Abu Dhabi Combat Club)
- **Official Results**: [ADCC Events & Results](https://adcombat.com/adcc-events/results/)
- **Past Events**: Historical results from ADCC competitions worldwide
- **Weight Classes**: Official ADCC weight divisions and rules
- **Hall of Fame**: [ADCC Hall of Fame](https://adcombat.com/adcc-hall-of-fame/)

#### IBJJF (International Brazilian Jiu-Jitsu Federation)
- **Official Website**: [IBJJF.org](https://ibjjf.com/)
- **Competition Results**: [IBJJF Results](https://ibjjf.com/results/)
- **Rankings**: [IBJJF Rankings](https://ibjjf.com/rankings/)
- **Rules**: [IBJJF Rules](https://ibjjf.com/rules/)
- **Weight Classes**: Official IBJJF weight divisions

#### Grappling Industries
- **Website**: [Grappling Industries](https://grapplingindustries.com/)
- **Results**: Event results and brackets
- **Registration**: Competition registration data

#### Smoothcomp
- **Platform**: [Smoothcomp.com](https://smoothcomp.com/)
- **API Access**: For tournament data export
- **Event Management**: Competition organization tools

### Regional Organizations

#### Europe
- **UAEJJF**: [UAE Jiu-Jitsu Federation](https://uaejjf.com/)
- **JJIF**: [Ju-Jitsu International Federation](https://jjif.sport/)
- **EJJF**: [European Jiu-Jitsu Federation](https://ejjf.org/)

#### North America
- **NABJJF**: [North American BJJ Federation](https://nabjjf.com/)
- **US Grappling**: [US Grappling](https://usgrappling.com/)

## Data Aggregators & Analytics

### FloGrappling
- **Website**: [FloGrappling](https://www.flograppling.com/)
- **Rankings**: [FloGrappling Rankings](https://www.flograppling.com/rankings)
- **News & Analysis**: Competition coverage and statistics
- **Video Content**: Match footage and technique analysis

### Less Impressed, More Involved
- **Website**: [Less Impressed, More Involved](https://lessimpressedmoreinvolved.com/)
- **Statistical Analysis**: Advanced BJJ statistics and metrics
- **Data Visualizations**: Charts and graphs for competition analysis
- **Research**: Academic-style analysis of BJJ data

## Kaggle Datasets

## Technical Resources

### APIs and Data Access

#### Smoothcomp API
- **Documentation**: [Smoothcomp API Docs](https://smoothcomp.com/api)
- **Authentication**: API key required
- **Data Types**: Tournament results, brackets, registrations

#### IBJJF Data
- **Scraping**: Results pages are publicly accessible
- **Format**: HTML tables and PDF results
- **Rate Limiting**: Considerate scraping recommended

#### ADCC Data
- **Web Scraping**: Results available on official website
- **Format**: HTML-based results pages
- **Historical Data**: Extensive archive of past events

### Data Formats

#### Common Formats
- **CSV**: Competition results, rankings
- **JSON**: API responses, structured data
- **Parquet**: Efficient storage for large datasets
- **PDF**: Official results documents

#### Schema Standards
- **Athlete IDs**: Consistent identification across sources
- **Weight Classes**: Standardized weight divisions
- **Belt Levels**: IBJJF belt progression system
- **Competition Types**: Gi vs No-Gi classifications

## Data Collection Tools

### Web Scraping
- **BeautifulSoup**: HTML parsing for results pages
- **Selenium**: Dynamic content extraction
- **Scrapy**: Large-scale web scraping framework

### APIs
- **REST APIs**: Standard HTTP-based data access
- **GraphQL**: Flexible query-based data retrieval
- **Rate Limiting**: Respectful API usage practices

## Legal and Ethical Considerations

### Data Usage
- **Terms of Service**: Respect website terms and conditions
- **Rate Limiting**: Avoid overwhelming servers
- **Attribution**: Credit data sources appropriately
- **Privacy**: Protect athlete personal information

### Best Practices
- **Caching**: Store data locally to reduce API calls
- **Error Handling**: Graceful failure and retry logic
- **Documentation**: Document data sources and collection methods
- **Updates**: Regular data refresh schedules
